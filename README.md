# Mangaba Reunião — página

Página pública do Mangaba Reunião, publicada pelo GitHub Pages a partir da raiz da branch `main`.

- Tema: [Start Bootstrap New Age](https://startbootstrap.com/theme/new-age) (MIT, licença em `LICENSE-template-start-bootstrap.txt`). A identidade da Mangaba fica em `css/mangaba.css`; o `css/styles.css` é o do tema, sem alterações.
- `assets/img/tela-app.png` é a interface real do app, gerada por `scripts/capturar-tela.js` no repositório do app (transcrição do Whisper e respostas ao vivo do titan e do Brier).
- O código do app fica em um repositório privado.
